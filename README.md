## 🧠 Descripción

**RMNMouse** es una herramienta interactiva que utiliza una **cámara web** para controlar el cursor mediante **gestos de la mano**.  
Su principal objetivo es **asistir en la rehabilitación motora** de niños y personas con movilidad reducida, ofreciendo una alternativa intuitiva y divertida al uso del mouse tradicional.
